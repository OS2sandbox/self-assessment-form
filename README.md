A simple, user-friendly self-assessment form for OS2 governance evaluation.

A simple web-based alternative to the current [Markdown-based governance assessment template](https://github.com/OS2offdig/governance_report_template/blob/main/assessment_template.md) with an easy-to-use web form.

[//]: # ( features )

## Features

- **Easy to use** — Intuitive web interface, no technical skills required

- **Export ready** — JSON output integrates with other loosely coupled Ops workflows
- **Standards-based** — Based in Open Standards Schema for flexibility and reuse.
